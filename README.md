# mvi

**Быстрый терминальный просмотрщик и редактор markdown** (и не только) на Go.

`mvi` открывает файл прямо в терминале: markdown рендерится в красивый
документ, код подсвечивается, текст и логи показываются дословно. Внутри
есть встроенный vim-движок, файловый браузер, поиск, переходы по ссылкам
и мышь.

```
mvi                 # открыть README.md текущего каталога
mvi NOTES.md        # открыть файл
mvi --style dracula main.go
```

## Возможности

- **Просмотр markdown** — рендер glamour с восемью темами (`auto`, `dark`,
  `light`, `dracula`, `tokyo-night`, `pink`, `ascii`, `notty`).
- **Любой текстовый файл** — `.txt`, `.log`, `.csv`, конфиги; тип файла
  определяется по расширению и по содержимому (первые 8 КБ).
- **Подсветка кода** — chroma для `.go`, `.py`, `.js`, `.rs`, `.sh`,
  `.yaml`, `.json` и т.д.; схема наследуется от темы `mvi`.
- **Защита от бинарников** — файл с нулевыми байтами отклоняется с
  сообщением, а не открывается как мусор.
- **Редактирование** — встроенный vim-движок (нормальный/визуальный режим,
  счётчики, текстовые объекты) либо внешний `nvim`/`vim`.
- **Файловый браузер** — навигация, создание (`n`/`N`) и удаление (`d`)
  файлов и каталогов.
- **Поиск и навигация** — `/` по документу с `n`/`N`, ссылки через `o`,
  история переходов `ctrl+o` / `tab` как в vim.
- **Мышь** — колесо и клики работают в просмотре.

## Установка

### Одной командой

```bash
curl -fsSL https://raw.githubusercontent.com/ApollieKastro/MyViewer/main/install.sh | bash
```

Установщик сам выбирает способ: если есть [Go](https://go.dev/dl/) —
соберёт из исходников, если нет — скачает готовый бинарник из
[Releases](https://github.com/ApollieKastro/MyViewer/releases)
(linux/darwin, amd64/arm64). Ставится в `~/.local/bin`, рядом создаётся
симлинк `mviewer`.

Обновление и удаление — тоже одной командой:

```bash
curl -fsSL https://raw.githubusercontent.com/ApollieKastro/MyViewer/main/install.sh | bash -s -- update
curl -fsSL https://raw.githubusercontent.com/ApollieKastro/MyViewer/main/install.sh | bash -s -- remove
```

### Из исходников

```bash
git clone https://github.com/ApollieKastro/MyViewer.git
cd MyViewer
./install.sh install      # сборка + копирование в ~/.local/bin
```

`install.sh` также понимает `update` и `remove`, без аргументов —
интерактивное меню.

### Вручную

```bash
go build -o mvi .
mv mvi ~/.local/bin/
```

## Использование

```
mvi [опции] [файл]
```

Без аргумента открывается `README.md` текущего каталога, иначе первый
markdown, затем `.txt`/`.log`, иначе — файловый браузер.

| Опция | Описание |
|---|---|
| `-h`, `--help` | справка |
| `-v`, `--version` | версия |
| `--style <тема>` | тема рендера: `auto`, `dark`, `light`, `dracula`, `tokyo-night`, `pink`, `ascii`, `notty` |

### Основные клавиши

| Клавиша | Действие |
|---|---|
| `q` | выход |
| `?` | справка |
| `s` | настройки |
| `e` | редактировать (`nvim` → `vim` → встроенный) |
| `/`, `n`/`N` | поиск, следующее/предыдущее совпадение |
| `o` | список ссылок документа |
| `ctrl+o` / `tab` | назад / вперёд по истории ссылок |
| `ctrl+n` | номера строк вкл/выкл |
| `n` / `N` | новый файл / каталог (в браузере) |
| `d` | удалить (в браузере, с подтверждением) |
| мышь | колесо — прокрутка, клик — выбор |

Vim-режим включён по умолчанию: в просмотре `j`/`k`, `g`/`G`,
`ctrl+d`/`ctrl+u`, `f`/`b`; в редакторе — полный нормальный режим
`hjkl`, `w`/`b`/`e`, `d`/`y`/`c`, `p`, `u`, визуальный режим, счётчики.

## Поддерживаемые форматы

| Формат | Просмотр | Редактирование |
|---|---|---|
| Markdown (`.md`, `.mdx`, `.rmd`, `.qmd`, …) | рендер glamour | да |
| Текст (`.txt`, `.log`, `.csv`) | дословно | да |
| Код (`.go`, `.py`, `.js`, `.rs`, …) | подсветка chroma | да |
| Makefile, `.ini`, `.conf`, `.toml`, `.env` | дословно | да |
| `rst`, `adoc`, `org`, `html`, `tex` | сырой режим | да |
| Бинарные (`.png`, `.pdf`, …) | отказ с сообщением | — |

Подробная таблица и планы — в [ROADMAP.md](ROADMAP.md).

## Структура проекта

```
mviewer/
├── main.go              # точка входа, флаги, запуск TUI
├── internal/
│   ├── app/             # оркестрация: режимы, история, внешний редактор
│   ├── browser/         # файловый браузер
│   ├── config/          # ~/.config/mviewer/config.json
│   ├── document/        # типы файлов, ссылки, классификация
│   ├── editor/          # встроенный vim-движок
│   ├── render/          # рендер markdown/кода, темы, детект фона
│   ├── ui/              # справка, настройки, статусбар, стили
│   └── viewer/          # поиск по документу
├── install.sh           # установка / обновление / удаление
└── ROADMAP.md           # план развития
```
